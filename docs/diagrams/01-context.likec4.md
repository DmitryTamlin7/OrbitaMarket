## 4. Модели системы

Версия документа: **1.0**

Все исходники диаграмм находятся в каталоге [`docs/diagrams/`](diagrams/).

| № | Диаграмма | Точка зрения | Назначение | Файл | Связанные требования / сценарии |
|---|-----------|--------------|------------|------|---------------------------------|
| 1 | System Context | Контекст | Границы системы, пользователь, основные взаимодействия | `likec4/views.c4` → view `context` | FR-1…FR-6, NFR-1 |
| 2 | Containers | Структура | Микросервисы, Kafka, базы данных и связи между ними | `likec4/views.c4` → view `containers` | NFR-1, NFR-3, NFR-5 |
| 3 | Sequence (успех) | Взаимодействие | Успешный путь: создание заказа → оплата → PAID | `likec4/views.c4` → `sequence_success` | FR-1, FR-6 |
| 4 | Sequence (ошибка) | Взаимодействие | Ошибка оплаты (недостаточно средств) → FAILED | `likec4/views.c4` → `sequence_error` | FR-6 |
| 5 | Activity | Контекст / процесс | Основной бизнес-процесс заказа и оплаты | `02-activity.mmd` | FR-1, FR-6 |
| 6 | Use Case | Взаимодействие | Варианты использования, согласованные с FR | `03-usecase.mmd` | FR-1…FR-8 |
| 7 | Class / Data Model | Структура | Сущности предметной области и связи | `06-class.mmd` | Термины из раздела 1 |
| 8 | State | События | Жизненный цикл заказа | `07-state.mmd` | FR-1, FR-6, FR-8 |

### Примечания
- Архитектурные views (Context, Containers, Sequence) выполнены в **LikeC4**.
- Поведенческие и структурные UML-диаграммы (Activity, Use Case, Class, State) выполнены в **Mermaid** для максимальной читаемости и соответствия классическим нотациям.
- Диаграммы состояния и последовательности иллюстрируют один и тот же объект — **Order**.
